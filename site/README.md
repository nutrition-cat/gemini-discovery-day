# Gemini Discovery Day 参加者限定プロンプトギャラリー 運用ガイド

日本の大学生向け 実践型AI共創イベント「Gemini Discovery Day」（2026.11.25 大手町 3x3Lab Future）の参加者特典Webサイトです。

---

## 1. サイトの閲覧・プレビュー方法

現在ローカルサーバーが起動しています。ブラウザで以下のURLを開くとサイトを確認できます。

👉 **http://localhost:8080/**

※サーバーを再起動したい場合は、PowerShell等で以下のコマンドを実行してください：
```bash
python -m http.server 8080 --directory site
```

---

## 2. 実装されている主な機能

1. **サイバー＆グラスモーフィズムデザイン**:
   - イベント告知ポスターの世界観（ディープスペースネイビー背景、サイバーグリッド、光るパーティクルオーブ、ネオングロー）を完全再現。
   - Gemini公式ロゴは使わず、イベントポスターのモチーフを活かしたスタイリッシュな幾何学デザイン。
2. **目的・効果が直感でわかるUI**:
   - 各カードに専用のSVGアイコン、カテゴリバッジ、機能タグ、要約文を配置し、文字だらけのダサさを徹底排除。
   - カードホバー時の立体浮遊＆ネオン発光エフェクト。
3. **ワンクリック即時コピー**:
   - カード右下の⚡アイコン、またはモーダル内のコピーボタンで、即座にクリップボードにコピー可能（コピー完了トースト表示）。
4. **🤖 AIで自分用にカスタマイズ（Gemini API連携）**:
   - モーダル内の「AIで自分用にカスタマイズ」タブから、自分の専攻や状況を入力。
   - 画面右上の「⚙️ 設定」からGemini APIキーを登録すると、Gemini 1.5 Flash / Pro がその場であなた専用の最適化プロンプトを自動生成！
   - ※APIキー未入力時でも、動的テンプレート補完エンジンが即座にカスタマイズ版プロンプトを組み立ててくれます。
5. **合言葉（パスワード）入場ゲート**:
   - 開発・確認中は「プレビュー中 (認証OFF)」になっており、パスワードなしで全画面を快適に操作できます。
   - 右上の「⚙️ 設定」から「パスワード認証ゲート（本番用）」をONにすると、合言葉ロック画面が有効になります。
   - **初期合言葉**: `discovery2026`（他に `gemini`, `1125` も有効）

## 3. 今後のプロンプト差し替え・更新手順

夜のミーティング等で「新しいTSV」が決まった場合、以下の手順で一瞬でサイトに反映できます。

1. 新しいTSVファイルを本フォルダに配置（または `80prompt.tsv` を上書き）
2. 以下のコマンドを実行：
   ```bash
   python update_prompts.py
   ```
3. `site/prompts-data.js` が自動更新されるので、ブラウザをリロードするだけで完了です！

※手動でプロンプトのテキストやTipsを微修正したい場合は、`site/prompts-data.js` を直接テキストエディタで編集することも可能です。

## 4. 本番Webサイトとしての公開方法（無料・数分で可能）

このサイトは外部データベースや重いバックエンドを持たない軽量な静的Webサイト（HTML/CSS/JS）のため、どこにでも無料で簡単に公開できます：

- **Vercel / Netlify**: `site` フォルダをドラッグ＆ドロップするだけで即座に公開URL（HTTPS対応）が発行されます。
- **GitHub Pages**: リポジトリを作成し、GitHub Pagesの公開ディレクトリを `site` に指定するだけで無料公開可能。
- **Cloudflare Pages**: 超高速CDNで全世界に配信可能。
